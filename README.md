# TW1 Mods

Fertige Mods (nur kompiliert, kein Quelltext) für Two Worlds 1 von MedievalDev. Sie lassen sich auch über den [TW1 Mod Manager](https://github.com/MedievalDev/TW1_ModManager) installieren.

| Mod | Version | Dateien |
|---|---|---|
| [NPC Riders](mods/npc-riders) | 1.5 | NPC_Riders.wd, NPC_Riders_DE.wd |
| [VoiceFix Bugfix Only](mods/voicefix-bugfix) | 1.0 | VoiceFix_Bugfix.wd |
| [VoiceFix Complete](mods/voicefix-complete) | 1.0 | VoiceFix_Complete.wd |
| [VoiceFix Dialogs (German only)](mods/voicefix-dialogs-de) | 1.0 | VoiceFix_Dialogs_DE.wd |

Die Mods sind nur kompiliert abgelegt. Eine Beschreibung steht in der README jeder Mod.
